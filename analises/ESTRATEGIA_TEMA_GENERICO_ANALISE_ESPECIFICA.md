# 🎯 ESTRATÉGIA: COMO TRABALHAR COM TEMA GENÉRICO + ANÁLISE ESPECÍFICA
**Situação:** Em TCC 2 (UERJ), tema já aprovado em TCC 1, não pode mudar.  
**Desafio:** Tema genérico ("Estudo das metodologias...") vs análise específica (paradoxo/agilidade de fachada)  
**Solução:** Reformalizar a NARRATIVA para que fique coerente

---

## 🔄 COMO FAZER FUNCIONAR

### **Estratégia: "Ao estudar, descobri um paradoxo"**

A banca ACEITA se você contar assim:

```
"Comecei com o tema: 'Estudo das metodologias mais adotadas'

Durante a pesquisa (Cap 1-2), estudei:
- História dos frameworks
- Como evoluíram
- Quais são mais adotadas

MAS descobri algo inesperado (Cap 3):
- Alta adoção declarada (93%)
- Baixa maturidade de implementação (38%)
- Gap entre o que se diz fazer e o que se realiza

Isso gerou uma pergunta: POR QUÊ?

E isso é o que Cap 4 responde."
```

**Isso é legítimo porque:**
✅ Você estudou as metodologias (cumpriu tema)  
✅ Durante o estudo, encontrou um paradoxo (descoberta)  
✅ Investigou as causas (análise crítica)  
✅ Explicou o fenômeno (contribuição)

---

## 📐 COMO REFORMULAR CADA CAPÍTULO

### **CAP 1 - "FUNDAMENTOS TEÓRICOS"**

**Sua narrativa atual:**
"Vou mostrar que frameworks convergiram para os mesmos valores"

**Reformular para:**
"Ao estudar as metodologias mais adotadas (Scrum, Kanban, SAFe, LeSS, DevOps), observo que:
1. Emergiram de contextos diferentes (Cap 1.1-1.4)
2. Convergiram para os mesmos valores (síntese Cap 1)
3. MAS as organizações declaram adotá-los sem internalizar os valores
4. Isso cria uma aparência de agilidade sem a realidade"

**Resultado:** Cap 1 ainda é estudo das metodologias, mas já sinaliza o paradoxo.

---

### **CAP 2 - METODOLOGIA**

**Permanece igual, mas adicione uma frase na Introdução do Cap 2:**

"Este capítulo descreve como esta pesquisa estuda as metodologias mais adotadas. Durante essa investigação, utilizou-se abordagem qualitativa que permite não apenas DESCREVER os frameworks, mas ANALISAR CRITICAMENTE o gap entre sua prescrição teórica e sua implementação prática nas organizações."

**Resultado:** Deixa claro que metodologia qualitativa é apropriada porque permite análise crítica, não só descrição.

---

### **CAP 3 - "ANÁLISE CRÍTICA"**

**Título reformulado:**
"ANÁLISE CRÍTICA: **As Metodologias Mais Adotadas e o Paradoxo de Sua Implementação**"

**Introdução do Cap 3 reformulada:**

"Os capítulos anteriores apresentaram as metodologias mais adotadas no mercado de tecnologia e sua evolução. Este capítulo desloca o foco: passa da história e da teoria para a realidade observável. Se os capítulos anteriores mostraram como os frameworks evoluíram, este capítulo confronta o panorama de adoção declarada com os dados reais de performance. O resultado é uma contradição fundamental: **as organizações declaram adotar as metodologias mais comuns (Scrum, Kanban), mas os dados de performance revelam um quadro bem mais complexo.**"

**Resultado:** Cap 3 fica como "consequência natural" de estudar as metodologias — você as estudou (Cap 1), aprendeu como funcionam (Cap 2), agora analisa como são REALMENTE implementadas (Cap 3).

---

### **CAP 4 - "DISCUSSÃO"**

**Título reformulado:**
"DISCUSSÃO: **Por Que o Gap Persiste Mesmo Com as Metodologias Disponíveis**"

**Introdução reformulada:**

"Os dados analisados no Cap 3 revelam um paradoxo: as organizações adotam as metodologias mais amplamente prescritas (Scrum 93%, Kanban 82%) mas não colhem os resultados esperados. Este capítulo explica por quê. A resposta não está nos frameworks em si — como Cap 1 mostrou, os frameworks amadureceram e convergiram para os mesmos valores. A resposta está em como as organizações implementam (ou não) esses frameworks."

**Resultado:** Cap 4 é "explicação do por quê" — natural na progressão do estudo das metodologias.

---

### **CAP 5 - CONCLUSÕES**

**Título reformulado:**
"CONCLUSÕES: **Implicações do Estudo das Metodologias Mais Adotadas para a Prática Organizacional**"

**Estrutura:**

1. O que descobri ao estudar as metodologias
2. O paradoxo que encontrei
3. A explicação para o paradoxo
4. O que isso significa para quem trabalha com essas metodologias

**Resultado:** Conclusões ficam como "consequência lógica" de ter estudado as metodologias.

## 🔗 NARRATIVA COMPLETA (Como Contar para Banca)

```
TEMA: "Estudo das metodologias de desenvolvimento de software mais adotadas"

DESCOBERTA: Durante o estudo, encontrei um paradoxo

CAP 1: Estudei as metodologias (história, evolução, frameworks)
↓
CAP 2: Defini como estudaria (metodologia qualitativa)
↓
CAP 3: Analisei dados de adoção vs performance (paradoxo revelado)
↓
CAP 4: Expliquei por que o paradoxo existe (cultura como condição)
↓
CAP 5: Conclui qual é o significado disso para prática

RESULTADO: Um estudo que começou descritivo e se tornou crítico-explicativo
```

2. ✅ **Adiciona valor:** Não fica só em descrição, vai para análise crítica
3. ✅ **Narrativa coerente:** Descoberta natural durante pesquisa
4. ✅ **Metodologia apropriada:** Qualitativa permite análise crítica
5. ✅ **Contribuição clara:** Explicar paradoxo é mais valioso que só descrever

**A banca vê:** "Ela começou estudando um tema amplo e através da pesquisa rigorosa descobriu um fenômeno importante que explica."

Isso é **pesquisa de verdade**, não apenas execução de tema.

## 📝 AJUSTES MÍNIMOS NECESSÁRIOS

Para fazer a narrativa funcionar, precisam de:

### **Na Introdução do TCC (bem no início):**

Adicionar parágrafo que sinalize a progressão:

```
"Este trabalho examina as metodologias de desenvolvimento de software 
mais adotadas no mercado de tecnologia. Através dessa investigação, 
revelou-se uma contradição fundamental: enquanto as organizações 
declaram maciçamente adotar frameworks ágeis (93% utilizam Scrum), 
os indicadores objetivos de desempenho mostram um quadro heterogêneo 
e frequentemente distante das promessas dos frameworks. 

Essa contradição estrutura o trabalho: os capítulos iniciais estudam
```

Adicionar bridge que conecte ao estudo das metodologias:

```

este capítulo desloca a análise para a realidade de sua implementação."
```

### **Na Introdução do Cap 4:**

Adicionar contexto que ligue à investigação das metodologias:

```
"Os frameworks estudados nos capítulos anteriores promovem valores 
específicos. Este capítulo investiga por que esses valores frequentemente 
não se materializam nas organizações que adotam os frameworks."
```
