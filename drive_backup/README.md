## 💾 Como Usar Esses Arquivos

### Para a Monografia:
1. Cite os PDFs usando referências ABNT (ver `referencias_estruturadas.md`)
2. Use dados dos PDFs para embasar argumentos
3. Consulte rascunhos para não duplicar conteúdo

### Para Apresentação:
1. Consulte Standish Chaos Report para histórico
2. Use DORA 2024-2025 para métricas atualizadas
3. Reference NTT DATA para contexto regional

### Para Revisão:
1. Verifique versão mais recente em "TCC - Versão Trabalhada 2026"
2. Revise fichamentos para não perder insights
3. Consulte orientadora via pasta compartilhada
